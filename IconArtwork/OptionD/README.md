# Option D: The Sow

The verb, not the object. Five stones arc counter-clockwise into a store, each
larger and brighter than the one behind it, over the warm dark of the Embers
backdrop. The only direction here that shows the game being *played*.

Import these layers into Icon Composer in numeric order:
1. `01-night.svg`
2. `02-store.svg`
3. `03-trail.svg`
4. `04-stones.svg`
5. `05-light.svg`

Recommended Icon Composer settings:
- Liquid Glass on the stones group, Individual mode, specular high — the size
  ramp does the work and glossier stones sharpen it.
- Keep the trail layer under the stones and faint; at 40pt it should read as
  motion, not as a drawn line.
- The store's brass rim is the only hard edge. Don't add board detail behind it;
  the emptiness is what makes the arc legible.

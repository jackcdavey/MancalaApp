# Option C: Walnut Table

The product shot. A walnut slab — the default `BoardMaterialStyle.walnut` —
tilted and cropped past both edges so it reads as an object on a lamplit table
rather than a diagram of one. Says "mancala" before the name is read.

Import these layers into Icon Composer in numeric order:
1. `01-ground.svg`
2. `02-slab.svg`
3. `03-wells.svg`
4. `04-stones.svg`
5. `05-light.svg`

Recommended Icon Composer settings:
- Liquid Glass on the stones group, Individual mode; leave the slab and wells
  opaque so the wood keeps its grain.
- Specular on, warm — the whole direction rests on the lamp reading as warm.
- The tilt is the identity. If it has to be squared up for a platform, drop the
  crop too and it becomes Option B in wood.
